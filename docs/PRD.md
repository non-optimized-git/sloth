# 数览 Sloth · PRD

## 产品概述

**数览 Sloth** 是一款纯前端问卷数据可视化工具，专注于快速查看和对比调研数据。上传 Excel 文件后自动生成交互式图表，支持表头交叉分析、分组管理、配置导出/导入、夜览模式。

**技术架构：** 单文件 HTML（index.html），ECharts 5.5 + XLSX.js，零后端依赖。

---

## 核心功能

### 1. 数据上传与解析
- 上传 .xlsx / .xls 文件，第一行为题目标题，下方为数据行
- 自动识别单选题 / 多选题（含英文逗号分隔的选项）
- 自动计算每题的选项频次、百分比、样本量

### 2. 图表展示
- 水平柱状图（ECharts），每题独立渲染
- 支持 Total 列 + 多个表头列并排对比
- 数据格式切换：百分比 / 数值 / 两者
- 小数位数：0位 / 1位 / 2位
- 统一浅色柱体，支持滑块调节粗细（8-28px）
- 柱体末端圆角，加载动画从上到下逐条渐入

### 3. 差异高亮
- 显示设置中开启「显示差异」
- 自动标记每道题表头列中的横向最高值（绿色背景）和最低值（红色背景）
- Total 列不参与对比

### 4. 表头库系统
- **添加表头**：全局入口，支持简单表头（单题目选项）和复杂表头（跨题目合并）
- **存储与激活**：表头存储在右侧工具箱，点击切换激活/取消，可同时激活多个
- **拖拽排序**：通过 ⠿ 手柄拖拽调整顺序，同步影响图表列序
- **编辑**：点击 ✎ 修改表头名称和筛选条件
- **删除**：点击 × 删除，需确认弹窗
- **清空**：一键清空所有表头，需确认弹窗

### 5. 分组管理
- 点击「＋ 添加分组」直接在第一行题目上方插入新分组
- 分组标题支持拖拽重定位，拖拽时显示绿色预览线
- 双击分组标题可直接编辑名称，回车确认
- 分组名称在左侧导航和右侧图表区域同步更新
- 删除分组需确认弹窗

### 6. 复制功能
- 点击「复制」生成 Markdown 表格格式
- 可直接粘贴到飞书等支持 Markdown 的平台
- 按钮状态反馈：复制 → 已复制，固定尺寸不变

### 7. 配置导出/导入
- **导出**：顶部 banner「导出」，下载 JSON 文件
- **导入**：顶部 banner「导入」，上传 JSON 恢复
- 配置包含：分组、表头库、显示模式、小数位数、差异开关、柱体粗细、主题

### 8. 左侧导航
- 固定左侧栏，宽度可拖拽调整（140-400px）
- 显示所有题目，支持题目分组展示
- 单选/多选题型标签颜色区分（青绿/琥珀）
- 点击导航项平滑滚动到对应图表
- 滚动页面时自动高亮当前可见题目

### 9. 夜览模式
- 顶部 banner 月亮/太阳按钮切换
- 自动检测系统偏好（prefers-color-scheme）
- 所有组件颜色自适应：背景、卡片、边框、文字、图表
- ECharts 图表颜色动态跟随主题

## 设计系统

### 色板（亮色）

| 令牌 | 值 | 用途 |
|------|----|------|
| --c-bg | #f7f3ee | 页面背景 |
| --c-card | #ffffff | 卡片背景 |
| --c-border | #e6ddd3 | 边框 |
| --c-brown | #5c4a3a | 主色调 |
| --c-green | #5a7a4a | 强调色 |
| --bar-color | #e0d7cc | 柱体色 |
| --t1 | #3c3228 | 主文字 |
| --t2 | #6b5d50 | 次文字 |
| --t3 | #a89880 | 辅助文字 |

### 色板（暗色）

| 令牌 | 值 |
|------|----|
| --c-bg | #1a1816 |
| --c-card | #242220 |
| --c-border | #3a3632 |
| --c-green | #7a9a6a |
| --bar-color | #5a524a |

### 字号体系

| 令牌 | 值 | 用途 |
|------|----|------|
| --f-xs | 8px | 微型标签 |
| --f-sm | 9px | 辅助文字 |
| --f-md | 11px | 次要内容 |
| --f-base | 12px | 正文 |
| --f-lg | 14px | 标题 |

### 圆角体系

| 令牌 | 值 | 用途 |
|------|----|------|
| --radius-s | 3px | 按钮、标签 |
| --radius-m | 5px | 卡片、输入框 |
| --radius-l | 8px | 弹窗 |

### 组件库

| 组件 | 类名 | 说明 |
|------|------|------|
| 按钮 | .btn | 统一按钮，支持 .primary / .danger / .ghost / .sm |
| 分段选择器 | .segmented > .seg | pill 形切换，白色滑块 |
| 开关 | .toggle-row > .toggle | iOS 风格 toggle |
| 弹窗 | .modal-overlay > .modal | 毛玻璃遮罩 + 白色卡片 |
