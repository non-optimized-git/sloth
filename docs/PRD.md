# 数览 Sloth · 产品需求文档（PRD）

> **版本**：v5.1  
> **最后更新**：2026-08-17  
> **产品定位**：纯前端问卷数据可视化工具

---

## 1. 产品概述

### 1.1 产品简介

**数览 Sloth** 是一款专注于问卷数据快速查看和对比的可视化工具。用户上传 Excel 文件后，自动生成交互式水平柱状图，支持表头交叉分析、分组管理、配置导出/导入、夜览模式等功能。

### 1.2 产品定位

| 维度 | 说明 |
|------|------|
| **目标用户** | 市场调研、用户研究、产品运营等需要快速查看问卷数据的人群 |
| **核心价值** | 零门槛、即时反馈、专注数据可视化（非数据收集） |
| **技术架构** | 单文件 HTML，ECharts 5.5 + XLSX.js，零后端依赖 |
| **设计风格** | 暖棕色 MUJI 风，克制、安静、易用 |

## 2. 用户场景

### 2.1 核心场景

| 场景 | 用户行为 | 产品响应 |
|------|----------|----------|
| 快速查看 | 上传 Excel，浏览各题分布 | 自动生成柱状图，左侧导航跳转 |
| 交叉分析 | 按性别/年龄等维度对比 | 添加表头，多列并排对比 |
| 数据导出 | 复制图表到报告 | 一键复制为 Markdown/HTML 表格 |
| 配置复用 | 保存分析配置 | 导出/导入 JSON 配置文件 |
| 多设备同步 | 登录后云端存储 | Supabase 云存储，文件管理 |

### 2.2 用户旅程

```
上传 Excel → 自动解析 → 查看图表 → 添加表头（交叉分析）→ 调整设置 → 复制/导出
     ↓
  登录（可选）→ 云端存储 → 多设备访问
```

## 3. 功能需求

### 3.1 数据上传与解析

**优先级**：P0（核心功能）

| 功能点 | 说明 | 状态 |
|--------|------|------|
| 文件格式 | 支持 .xlsx / .xls | ✅ |
| 拖拽上传 | 拖拽文件到上传区域 | ✅ |
| 点击上传 | 点击上传区域选择文件 | ✅ |
| 题型识别 | 自动识别单选/多选（含英文逗号） | ✅ |
| 空列过滤 | 自动跳过无数据的列 | ✅ |
| 高基数隐藏 | 选项 >30 个的题目自动隐藏（如用户ID） | ✅ |
| 解析反馈 | 显示数据条数、题目数量 | ✅ |

**技术细节**：
- 解析入口：`parseExcel(file)`
- 高基数阈值：`HIGH_CARDINALITY_THRESHOLD = 30`
- 数据结构：`questions[]` 数组，每题包含 `id`、`title`、`type`、`total`、`labels`、`counts`、`percents`

### 3.2 图表展示

**优先级**：P0（核心功能）

| 功能点 | 说明 | 状态 |
|--------|------|------|
| 图表类型 | 水平柱状图（ECharts） | ✅ |
| Total 列 | 每题默认显示全量数据 | ✅ |
| 多列对比 | 支持多个表头列并排 | ✅ |
| 数据格式 | 百分比 / 数值 / 两者 | ✅ |
| 小数位数 | 0位 / 1位 / 2位 | ✅ |
| 柱体粗细 | 滑块调节 8-28px | ✅ |
| 圆角柱体 | 末端圆角 `[0,5,5,0]` | ✅ |
| 加载动画 | 从上到下逐条渐入 | ✅ |
| 每题独立比例尺 | 不统一 xMax | ✅ |

**技术细节**：
- 渲染入口：`renderCharts()`
- 动画延迟：`animationDelay: idx => (revLabels.length-1-idx) * 35`
- 颜色获取：`getCSS('--bar-color')`

### 3.3 差异高亮

## 5. 数据结构

### 5.1 核心状态

```javascript
// 原始数据
let rawData = [];           // Excel 原始数据（JSON 数组）
let headers = [];           // Excel 列名数组（所有列）
let questions = [];         // 解析后的题目数组（跳过空列）

// 配置状态
let groups = [];            // 分组配置
let headerLibrary = [];     // 表头库
let activeHeaderIds = new Set(); // 当前激活的表头 ID
let hiddenQuestions = new Set(); // 被隐藏的题目索引

// 显示设置
let displayMode = 'percent'; // 数据格式：percent/count/both
let decimalPlaces = 0;      // 小数位数：0/1/2
let showDiff = false;       // 差异高亮
let barMaxWidth = 16;       // 柱体粗细（8-28px）
let currentTheme = 'light'; // 主题：light/dark
```

### 5.2 题目数据结构

```javascript
{
  id: 1,                    // 题号（从 1 开始）
  title: "性别",            // 题目标题（Excel 列名）
  type: "single",           // 题型：single/multi
  total: 337,               // 有效作答人数
  labels: ["女", "男"],     // 选项标签（按频次降序）
  counts: [180, 157],       // 各选项频次
  percents: [53.4, 46.6]    // 各选项百分比
}
```

### 5.3 表头数据结构

```javascript
{
  id: 1,                    // 唯一 ID
  name: "女性",             // 显示名称
  filters: [                // 筛选条件（OR 关系）
    {
      questionIdx: 0,       // 题目索引（questions 数组）
      optionLabel: "女"     // 选项标签
    }
  ],
  baseCount: 180            // 符合条件的样本量
}
```

### 5.4 分组数据结构

```javascript
{
  id: 1,                    // 唯一 ID
  name: "人口统计",         // 分组名称
  afterIndex: 2             // 出现在第 N 题之后（0-based）
}
```

### 5.5 配置文件结构

```json
{
  "version": 5,
  "groups": [...],
  "headerLibrary": [...],
  "headerIdCounter": 10,
  "activeHeaderIds": [1, 3],
  "displayMode": "percent",
  "decimalPlaces": 1,
  "showDiff": false,
  "barMaxWidth": 16,
  "currentTheme": "light"
}
```

## 6. 核心函数

| 函数 | 作用 |
|------|------|
| `parseExcel(file)` | 解析 Excel，自动识别单选/多选，过滤空列，自动隐藏高基数题目 |
| `computeSubset(qIdx, filterFn)` | 计算子集数据（使用 `questions[qIdx].title` 作为列名） |
| `buildFilter(hdr)` | 构建表头过滤器（使用 `questions[f.questionIdx].title` 作为列名） |
| `renderAll()` | = `renderSidebar()` + `renderMain()` + `renderHeaderLib()` + `autoSave()` |
| `renderCharts()` | 用 ECharts 渲染图表 |
| `copyQuestionData(qi)` | 复制为 HTML + 纯文本表格 |
| `openHeaderPicker()` | 打开表头选择器（简单/复杂） |
| `openEditHeader(idx)` | 编辑表头 |
| `sanitizeFileName(name)` | 清理文件名，替换非 ASCII 字符为下划线 |
| `escapeHtml(str)` | XSS 防护 |
| `autoSave()` | 自动保存配置到 localStorage |
| `showConfirm(title, msg, onOk)` | 显示确认弹窗 |

### B. 设计原则

1. **暖色系**：棕色为主，绿色点缀
2. **安静克制**：不抢用户注意力
3. **即时反馈**：设置改动实时生效
4. **一致性**：同类元素样式统一
5. **可访问性**：夜览模式、键盘导航、触摸友好

### C. 数据索引注意事项

**重要**：`headers` 数组和 `questions` 数组索引不一致！

- `headers`：包含 Excel 所有列名（包括空列）
- `questions`：只包含有数据的列（跳过空列）

**正确用法**：
```javascript
// ✅ 正确：使用 question.title 作为列名
const colName = questions[qIdx].title;
const value = row[colName];

// ❌ 错误：使用索引访问 headers
const value = row[headers[qIdx]]; // 可能索引错位！
```
