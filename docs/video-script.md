# 数览 Sloth · 产品介绍视频脚本

## 时长：约 90 秒

---

### 第 1 幕：开场（0-8s）
**画面：** 上传页，树懒 logo 缓缓出现
**字幕：** 数览 Sloth — 慢一点，看清数据
**解说：** 这是数览，一款问卷数据可视化工具。上传 Excel，自动生成交互式图表。

### 第 2 幕：上传（8-18s）
**画面：** 拖拽 Excel 文件到上传区域，页面切换到仪表盘
**字幕：** 上传 Excel → 自动识别题型 → 生成图表
**解说：** 把问卷数据拖进来，数览会自动识别单选和多选题，瞬间生成所有题目的图表。

### 第 3 幕：导航与浏览（18-28s）
**画面：** 点击左侧导航，页面平滑滚动到对应题目，高亮跟随
**字幕：** 左侧导航 · 点击跳转 · 滚动高亮
**解说：** 左侧导航可以快速定位任意一道题，滚动时自动高亮当前题目。

### 第 4 幕：表头交叉分析（28-48s）
**画面：** 点击工具箱"添加"→ 选择题目 → 勾选选项 → 确认 → 图表多列对比
**字幕：** 添加表头 → 交叉对比 → 发现差异
**解说：** 核心功能是表头交叉分析。选一个题目的选项作为表头，图表立刻变成多列并排对比，每列显示独立的样本量。还可以创建复杂表头，跨题目合并选项。

### 第 5 幕：显示设置（48-58s）
**画面：** 切换百分比/数值，开启差异高亮，调节柱体粗细
**字幕：** 数据格式 · 差异高亮 · 柱体粗细
**解说：** 显示设置可以切换数据格式、开启差异高亮标记最高值和最低值、调节柱体粗细。

### 第 6 幕：复制到飞书（58-66s）
**画面：** 点击复制按钮，显示"已复制"，切到飞书粘贴
**字幕：** 一键复制 Markdown → 粘贴到飞书
**解说：** 一键复制为 Markdown 表格，直接粘贴到飞书，格式完整保留。

### 第 7 幕：分组与夜览（66-78s）
**画面：** 添加分组 → 拖拽重定位 → 切换夜览模式
**字幕：** 分组管理 · 拖拽排序 · 夜览模式
**解说：** 可以给题目分组、拖拽调整顺序。点击右上角切换夜览模式，护眼又好看。

### 第 8 幕：配置导出（78-86s）
**画面：** 点击导出配置 → 下载 JSON
**字幕：** 导出配置 → 下次一键恢复
**解说：** 所有配置可以导出为 JSON 文件，下次打开直接导入，所有设置瞬间恢复。

### 第 9 幕：结尾（86-92s）
**画面：** 回到全景，树懒 logo
**字幕：** 数览 Sloth · 慢工出细活
**解说：** 数览，慢一点，看清数据。
