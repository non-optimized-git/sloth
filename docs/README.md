# 🦥 数览 Sloth

> 慢一点，看清数据。

纯前端问卷数据可视化工具，上传 Excel 自动生成交互式图表。

## 快速开始

```bash
# 直接用浏览器打开
open index.html
```

无需安装任何依赖，无需服务器。

## 使用流程

### 1. 上传数据
打开页面后，拖拽或点击上传 Excel 文件（.xlsx / .xls）。
- 第一行为题目标题
- 下方每行为一条数据
- 单选题：直接填写选项值
- 多选题：选项用英文逗号分隔

### 2. 查看图表
- 左侧导航：点击题目平滑跳转，滚动时自动高亮
- 图表区域：水平柱状图，鼠标悬停查看详情
- 顶部 banner：切换数据格式、小数位数
- 拖拽侧栏边缘可调整导航栏宽度

### 3. 添加表头（交叉分析）
点击工具箱「表头库」末尾的「┄ 添加表头 ┄」虚线框按钮：

**简单表头：** 选一个题目 → 勾选选项 → 每个选项成为独立一列

**复杂表头：** 跨题目选多个选项 → 合并为一列 → 自定义列名

添加后表头存储在右侧工具箱：
- 点击切换激活/取消
- 拖拽 ⠿ 调整顺序
- 点击 ✎ 编辑名称和筛选条件
- 点击 × 删除（需确认）

主内容区底部有「🗑️ 清空所有表头」按钮，可一键清空所有表头。

### 4. 差异高亮
显示设置中开启「显示差异」，自动标记每题表头列中的最高值（绿色）和最低值（红色）。

### 5. 调节柱体粗细
工具箱「柱体粗细」滑块，范围 8-28px，实时预览。

### 6. 复制数据
点击图表右上角「复制」，生成 Markdown 表格，可直接粘贴到飞书。

### 7. 配置管理
- **导出**：顶部「导出」→ 下载 JSON
- **导入**：顶部「导入」→ 上传 JSON 恢复所有配置

配置包含：分组、表头库、显示模式、小数位数、差异开关、柱体粗细、主题。

### 8. 题目分组
- 点击左侧导航「＋ 添加分组」→ 在第一行题目上方插入新分组
- 拖拽分组标题可重定位（绿色预览线指示位置）
- 双击分组标题直接编辑名称
- 删除分组需确认

### 9. 夜览模式
顶部 banner 右侧 🌙 按钮切换亮/暗主题，自动检测系统偏好。

### 10. 题目显示/隐藏
左侧导航每个题目左侧有复选框（☑），默认全部显示。
- 取消勾选可隐藏不需要的题目，提高分析效率
- 隐藏状态自动保存到配置文件
- 高基数题目（选项超过 30 个，如用户ID）首次打开时自动隐藏，避免卡顿

### 11. 用户登录与云存储
点击顶部「🔐 登录」按钮，使用邮箱密码注册/登录：
- 登录后文件自动上传到 Supabase 云端存储
- 点击「📁 文件」查看、下载、删除云端文件
- 未登录时完全离线可用，数据仅存本地浏览器

## 示例数据格式

| 性别 | 年龄 | 购买渠道 | 满意度 |
|------|------|----------|--------|
| 男 | 25-34 | 线上,线下 | 非常满意 |
| 女 | 18-24 | 线上 | 满意 |
| 女 | 35-44 | 线下,代购 | 一般 |

- 「性别」「年龄」「满意度」→ 自动识别为单选
- 「购买渠道」→ 自动识别为多选（含逗号）

## 设计风格

MUJI 风格，大地色调，树懒元素点缀。支持亮色/暗色双主题。统一设计系统：按钮、分段选择器、开关、弹窗等组件风格一致。

## 技术栈

- **ECharts 5.5** — 图表渲染
- **XLSX.js** — Excel 解析
- **Supabase** — 用户认证和云存储（可选）
- **Playwright** — 自动化测试
- 纯 HTML/CSS/JS，单文件，零依赖
